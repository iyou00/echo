# Echo App

Electron + React + TypeScript implementation for Echo v0.1.

## Commands

```bash
npm install
npm run rebuild:native
npm run dev
npm run build
npm run dist
```

## Notes

- Product specs live one directory up in `../PRD.md`, `../specs`, `../features`, `../prompts`, and `../design`.
- v0.1 shows recommended songs as cards. Real playback is planned for v0.2.
- LLM settings are configured inside the app and saved locally with Electron `safeStorage`.
