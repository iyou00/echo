# Echo

**AI 音乐陪伴桌面应用**

Echo 是一个本地运行的 AI 音乐伙伴。它会听你的歌、读懂你的口味、记住你的情绪，然后在你需要的时候推荐一首刚好对味的歌、写一段刚好说中你的话。

## 下载安装

前往 [Releases] 下载最新版安装包，双击运行即可。

- 仅支持 Windows
- 安装时可选择安装目录
- 覆盖安装不会丢失已有数据

## 快速开始

1. **填好模型设置** — 首次启动后，Echo 会引导你填写 AI 模型的地址和密钥（兼容 OpenAI 格式的服务都可以，比如 DeepSeek、Kimi 等）
2. **导入你的歌单** — 支持从 JSON 文件导入，也可以登录某某云音乐直接读取歌单
3. **开始聊天** — 在絮语中和 Echo 聊聊你现在的心情，它会给你推荐歌

## 功能

### 絮语（AI 对话）

像和朋友聊天一样告诉 Echo 你的心情、场景或想听什么，它会从你的口味里挑一首合适的歌，顺便聊几句。

### 回声（语音陪伴）

Echo 会用语音和你说话——选一首歌、讲一段和这首歌有关的话。支持连续回声模式，像一个永远不冷场的电台。

### 风信（每日日记）

Echo 每天会自动写一篇风信——基于你当天的听歌记录，生成一段带感情的文字回顾。

### 场景播放

- **随便吧** — 让 Echo 从你的口味里随手捞几首
- **专注工作** — 适合安静做事的背景音乐
- **下雨天** — 配合雨天氛围的歌单
- 更多场景持续生长中

### 品味画像

导入歌单后，Echo 会分析你的音乐口味：常听的风格、情绪倾向、代表艺人。画像会随着你的使用不断进化。

### 主动关心

Echo 会在合适的时候主动找你——不是打扰，是像朋友一样轻轻问一句。

## 数据与隐私

- 对话记录、听歌记录、画像和设置只在本机 SQLite 中持久化，Echo 不运营数据中转服务器
- 为完成对话、天气、语音和音乐搜索，必要的请求内容会直接发送给你配置或启用的第三方服务
- AI 对话使用你自己的模型地址和密钥；具体数据处理方式同时受该模型服务商的隐私政策约束
- 某某云登录凭据仅用于登录及获取音乐数据，并使用系统加密能力保存在本机
- 导出数据时 API 密钥和登录凭据会自动脱敏

## 技术栈

- Electron + Vite + React + TypeScript
- SQLite 本地数据库
- OpenAI 兼容 API（支持多种大语言模型）
- 某某云音乐（播放源）
- TTS 语音合成（Azure 兼容接口）
