## v0.3 退出标准

用户的实际体验:

1. 点顶栏"听音" tab → 看到抹茶绿待机态 + 一个"让 Echo 说一段"按钮
2. 点按钮 → Echo 用晓辰·知性的声音说 60-100 字开头(基于此刻情境 / 最近对话 / 昨日记忆)
3. 说完开头自然过渡到推荐一首歌
4. **TTS 念到推荐部分时,音乐已经在低音量播了**——人声完后音乐自动恢复正常音量
5. 文字三段着色实时跟着语音走
6. 整段说完不自动跳页 · 音乐继续播 · 文字停留 · 用户可继续听 / 再说一段 / 返回主对话

**v0.3 不做**:
- ❌ 主动推送(早晨问好 / 深夜陪聊)—— 留给"桌面音宠"版本
- ❌ 用户对 Echo 说话(STT 输入)—— 太复杂,放 v0.5+
- ❌ 多语言 TTS · 只做中文
- ❌ 用户在设置里换 TTS 服务商 UI(底层留扩展点,但不做切换 UI)

### 1.2 TTS 客户端封装

新文件 `src/main/tts/client.ts`:

```typescript
interface SynthesizeResult {
  ok: boolean;
  audioBuffer?: ArrayBuffer;  // mp3 二进制
  error?: { kind: string; message: string };
}

export async function synthesize(text: string): Promise<SynthesizeResult> {
  const settings = await getSettings();
  const { baseUrl, voice, speed, pitch } = settings.tts;
  
  try {
    const res = await fetch(`${baseUrl}/v1/audio/speech`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        input: text,
        voice,
        speed,
        pitch,
      }),
      signal: AbortSignal.timeout(30000),  // 30s 超时
    });
    
    if (!res.ok) {
      return { ok: false, error: { kind: 'HTTP_ERROR', message: `${res.status}` } };
    }
    
    const audioBuffer = await res.arrayBuffer();
    return { ok: true, audioBuffer };
  } catch (e) {
    return { ok: false, error: { kind: 'NETWORK_ERROR', message: humanize(e) } };
  }
}
```

```typescript
// src/main/weather/client.ts
export async function getWeather(city: string): Promise<WeatherInfo | null> {
  if (!city) return null;
  
  try {
    const res = await fetch(`https://wttr.in/${encodeURIComponent(city)}?format=j1&lang=zh`, {
      signal: AbortSignal.timeout(5000),
    });
    const data = await res.json();
    
    return {
      city,
      condition: data.current_condition[0].lang_zh?.[0]?.value ?? data.current_condition[0].weatherDesc[0].value,
      tempC: parseInt(data.current_condition[0].temp_C),
      humidity: parseInt(data.current_condition[0].humidity),
      // 简化输出:返回一个 Echo 用得上的"天气一句话"
      summary: `${condition},${tempC}°C`,  // 例 "阴 · 14°C"
    };
  } catch (e) {
    return null;  // 拿不到天气也没关系,Echo 不提就行
  }
}
```

```markdown
## 你要写什么

一段 60-100 字的"听音文案",分两个语义段(但**不分段**,连成一段读):

1. **开头**(30-50 字):基于此刻时间 / 最近对话 / 昨日记忆,起一个轻盈的头
```

```typescript
export async function generateListeningSegment(): Promise<ListeningSegment> {
  // Step 1: 收集上下文
  const recentConvs = await db.conversations.getRecent(5);
  const yesterdaySeal = await daySeal.getMostRecent();
  const taste = await taste.getProfile();
  const weather = await weather.getCurrent();
  const now = new Date();
  
  // Step 2: 通过 LLM tool use,先 find_tracks 找候选
  const candidates = await recommender.findTracks(sessionId, { 
    vibe: '基于此刻情境的推荐',
    n: 5,
  });
  
  // Step 3: 调 LLM,给它候选列表,让它写文案 + 选一首
  const llmResult = await llm.chat({
    system: SCENARIO_PROMPT,
    messages: [
      {
        role: 'user',
        content: buildContext({ recentConvs, yesterdaySeal, taste, weather, now, candidates }),
      },
    ],
    tools: [findTracksTool, playTracksTool],
  });
  
  // Step 4: 提取文案 + 选中的歌
  const text = llmResult.text;       // 60-100 字文案
  const selectedTrack = llmResult.toolCalls
    .find(t => t.name === 'play_tracks')
    ?.input.tracks[0];
  const trackRef = selectedTrack?.ref;
  const track = recommender.resolveRef(sessionId, trackRef);
  
  return {
    text,
    track,
    sessionId,
    generatedAt: now.toISOString(),
  };
}
```

#### 4.5.1 Audio Ducking(音量闪避)

```typescript
// 听音页组件挂载后
const audio = new Audio(ttsAudioUrl);
const wasPlaying = await playback.isPlaying();
let originalVolume = await playback.getVolume();

// TTS 开始播放,同时把背景音乐降到 30%
audio.addEventListener('play', () => {
  if (wasPlaying) {
    fadeVolume(playback, originalVolume, 30, 800);  // 800ms 淡入
  }
});

// TTS 播完
audio.addEventListener('ended', () => {
  if (wasPlaying) {
    fadeVolume(playback, 30, originalVolume, 1500);  // 1.5s 淡出恢复
  }
  // 如果之前没在播 · 此时启动 Echo 推荐的那首歌
  if (!wasPlaying && segment.track) {
    playback.play(segment.track);
  }
  setState('done');
});

audio.play();
```

#### 4.5.2 文字三段着色

Edge TTS 返回 word boundary 时间戳。但 wangwangit 这个代理**可能没透传 timing**——验证一下:

```bash
curl -X POST ".../v1/audio/speech" -d '{...}' -i
```

看响应 header 里有没有 `X-Word-Boundaries` 之类的字段。

**如果有 timing**:按精确时间分三段
**如果没有 timing**:**按文字总长度 / 音频总时长**线性计算每个字的时间点,体感上 95% 准

具体实现:

```typescript
const totalChars = text.length;
const totalDuration = audio.duration;

audio.addEventListener('timeupdate', () => {
  const progress = audio.currentTime / totalDuration;
  const splitIndex = Math.floor(totalChars * progress);
  
  setSaidText(text.slice(0, splitIndex));
  setNowChar(text[splitIndex] || '');
  setPendingText(text.slice(splitIndex + 1));
});
```

#### 4.5.4 推荐的歌何时开始播

**核心:Echo 推什么歌,用户能在文字里读到——但代码不去判断"念到歌名了"**。
**方案 A**(我们选这个):TTS 一开始播 → **800ms 后**(给 Echo 一个开头铺垫的呼吸)→ Echo 推荐的歌开始低音量播放。

```typescript
audio.addEventListener('play', () => {
  setTimeout(async () => {
    // 800ms 后,Echo 已经开始铺垫了,这时音乐淡入
    if (segment.track) {
      // 如果之前在播别的歌,先把它降下来(已经做了)
      // 如果之前没在播,启动 Echo 推荐的这首,以 30% 音量启动
      if (!wasPlaying) {
        await playback.play(segment.track, { initialVolume: 30 });
      }
    }
  }, 800);
});
```

注意 `playback.play({ initialVolume })` 可能需要在 v0.2 的 Player 里加这个参数。

## 给开发 AI 的工作准则

1. **核心约束**:Echo 推什么歌,用户能在文字里读到 · 代码**不去判断**"念到歌名了" · 用 800ms 固定延迟启动音乐(方案 A)
2. TTS 暂不做"换服务商" UI · 但底层留扩展点(`tts.baseUrl` 可改)
3. 听音页是"长留型"页面 · 不自动跳转 · DONE 态用户自己决定下一步
4. 音量曲线用 GainNode + 线性 fade(800ms 淡入 / 1500ms 淡出),不要硬切
5. 文字三段着色优先用 word boundary timing,没有 timing 就线性
6. **遇到无法判断的产品决策**:在文档底部 ❓ 区写一行,**不要擅自决定**
