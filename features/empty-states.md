# Feature · 空状态(Empty States)

> **核心理念**:每个"什么都没有"的瞬间,都是 Echo 性格的展示机会。
> 空状态不是"功能缺失",是"Echo 在等待你"。
>
> **对应 UI**:`design/empty-states.html`(15 个空态合集)
> **优先级**:P0 必须在 v0.1 上线;P1 在 v0.2 前补齐;P2 之后

---

## 1 · 设计原则

1. **每个空态都用 Echo 的口吻说话**——不用"暂无数据"、"列表为空"、"加载失败"这种系统话
2. **每个空态都给一个明确的下一步**(CTA 按钮、链接、或者"去做 X")
3. **错误用 Echo 视角包装**——"我连不上自己的脑子" 比 "401 Unauthorized" 好太多
4. **不弹 modal**——空态融入页面本身,不打断用户
5. **风格统一**——衬线大字 + 主色 CTA + 等宽元数据,和其他页保持一致

## 3 · 文案库 · Echo 在空态里会说的话

每个空态的文案都体现 Echo 人格(`specs/persona.md`)。**绝不**写成系统提示语。

| 场景 | 文案 |

| 还没歌单 | "嗨,我醒了——但我还没听过你的歌。给我看看?" |

| 场景 | 文案 |

## 4 · 实现要点

### 4.1 状态判断的"决策树"

每个页面进入时按这个顺序判断:

```
1. 没网?     → 顶部 banner ⑭(banner 不阻塞页面继续渲染)
2. LLM 未配置? → ① ④ ⑫
3. 没歌单?   → ② ④ (按页面而定)
4. 数据加载中? → ⑤ skeleton
5. 当前页业务空? → ⑥ ⑦ ⑩ ⑪
6. 业务执行失败? → ⑧ ⑬ ⑮
```

### 4.2 共用组件

建议封装一个 `<EmptyState>` 组件:

```tsx
<EmptyState
  icon="…"            // emoji 或 SVG
  quote={string}      // 衬线大字主文案
  sub={string?}       // 等宽小字补充
  cta={{ label, onClick, secondary? }[]}
  signature?={string} // 比如 "— Echo · 等你"
/>
```

### 4.3 不要的反例

- ❌ "暂无数据"
- ❌ "请先登录"  
- ❌ "您还未导入歌单,请前往设置页面进行导入操作"
- ❌ "Error 401: Unauthorized"
- ❌ 弹 modal 提示
- ❌ 红色 toast 上方飘过
