关 键 设 计 决 策
A 类型标签是给我们看的,真实通知不显示 · 设计稿里的 RECOMMEND / CHECK-IN / VOICE 标签只是为了让原型清晰。真实通知用户只看到一句话。但数据库里 care_pings.type 字段会记下来,用于产品分析。
B macOS 和 Windows 通知样式真的不同 · macOS 支持通知里的 action 按钮(右下方)· Windows 11 不支持 action,所以"今天别再提醒"做成通知体里的小链接。这个跨平台差异必须做对,否则 Windows 上会出现根本不工作的功能。
C 用户感知不到链路 · 推歌通知背后是 find_tracks → 选歌 → LLM 写文案 → 推送,但用户感受到的就是一句话 + 点开就放歌。这个"隐藏链路"是关键体验。
D 文案永远走 LLM,绝不用模板 · Echo 这个产品的灵魂就是"每一句话都新鲜"。每天 3 次 LLM 调用成本极低(几分钱),换 Echo 永远说人话,是稳赚的投资。
