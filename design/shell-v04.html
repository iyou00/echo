关 键 规 格
L A Y O U T   ·   顶栏单行总规则
  • 顶栏高度严格 44px · 内边距 8px 12px
  • 背景色 --ayin-50 · 整条可拖窗口(-webkit-app-region: drag)
  • 头像、Tab、窗口控件需要标 no-drag 让点击生效
  • 头像 28px · 在线点边框颜色 = 顶栏底色(嵌入感)
  • Tab 之间间距 22px · 字距 2.2px · 字号 10.5px
  • Tab active 标识只有"颜色变深 + 14px 主色短横",**不要底色填充**
  • 窗口控件 22px 圆 · 关闭 hover 变红 #C04A3A
T O O L B A R   ·   工具栏(子页面专用)
  • 高度 36px · 背景纯白 · 边距 9px 14px
  • 左侧:状态文字(衬线 italic + 等宽分隔符)
  • 右侧:圆形操作按钮 + 胶囊文字按钮混用
  • 圆形按钮 22px · 边框 0.5px rgba(0,0,0,0.1)
  • 胶囊按钮 11px 圆角 · 内边距 0 10px
  • 絮语页**没有**工具栏(因为对话本身没有元数据要展示)
B U T T O N   ·   按钮统一规则
  • 所有非主操作按钮:圆形 / 胶囊 + 描边 + 透明背景
  • Hover 时背景变 --ayin-50 · 边框变 --ayin-400 · 文字变 --ayin-700
  • 禁止:放大、抖动、阴影 · 只换背景色
  • 主操作按钮(发送、播放、▶):主色实心圆 · 不变
B O R D E R   ·   边框三套
  • 0.5px solid rgba(0,0,0,0.06) · 分隔线 · 默认
  • 0.5px solid rgba(99,153,34,0.3) · 主色描边 · 控件 active
  • 1.5px solid rgba(99,153,34,0.4) · 气泡左边线 · 唯一
  • 禁止:粗边框、双边框、虚线、内阴影边框
N A V   ·   导航关系
  • 絮语 / 风信 / 回声 / 拾音 是 Tab · 直接切换 · 无返回按钮
  • Echo 主页:点头像进入 · 顶栏头像变成"◁ 返回"按钮 · 工具栏齿轮 → 设置页
  • 设置页:从主页齿轮进入 · 顶栏左侧"◁ 返回"回到主页
  • Echo 主页和设置页**不在 Tab 里** · 因为它们是"关于 Echo 自己"的页面
D E V   ·   实现注意事项
  • 顶栏的 -webkit-app-region: drag 让窗口可拖 · 子元素标 no-drag 让点击生效
  • 关闭按钮第一次点击:弹友好提示"我藏到右下角去了,音乐继续放" + 最小化
  • 关闭按钮后续点击:静默最小化(读取 settings 标志)
  • Tab 切换:无路由跳转,纯 React state · 减少闪屏
  • "已陪伴 N 天" 数字每天 0 点更新
